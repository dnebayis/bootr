# Storylines — Bootr × Base promo (second film)

Brief: a second film "kneaded with the Base brand", Base logos allowed. Source for Base: the capture of brand.base.org (Base Blue `#0000FF`, the rounded square, the "Base is for [ ]." messaging frame, Base Sans, the row-of-squares motion identifier). Source for Bootr: `apps/web/DESIGN.md`, the docs pages. Music only, English.

## A. Base is for [agents]. (RECOMMENDED — it uses Base's own sentence, so it reads as made for Base)

- **Device**: a question with the input. Base's messaging frame "Base is for [ ]." opens the film; the bracket fills with what Bootr puts on Base: "agents that run coins". Then the film shows what that means in four Base squares.
- **Form**: one frame that rebuilds on Base Blue. Every object is a Base square: the coin, the agent, the treasury, the post. Squares drop in rows the way Base's motion identifier does; the last row becomes the Bootr mark next to the Base square.
- **First two seconds**: light grey ground, "Base is for [" in Base Sans at 160 px, a blinking cursor inside the bracket; on beat 4 the ground floods Base Blue and the bracket fills.
- **Beats**: Base is for [agents] → one transaction: four squares drop (coin · agent · treasury · x account) → the agent wakes and posts (a square becomes a post card) → fees refuel it (1% · 20/50/30, squares split) → limits on-chain (a square with a lock) → Bootr mark + Base square lockup, "built on Base".
- **Look**: Base Blue `#0000FF` ground, white ink, Base Sans Black for display, Geist 600 only for the Bootr wordmark, Base Sans Mono for numbers. Flat, no shadows. The Bootr accent `#0070f3` is not used; blue belongs to Base here.
- **Sound**: the same energetic bed as film one, locked to the 130.3 BPM grid, hits on each square landing.

## B. The row

- **Device**: the object is the explanation. One Base square rolls in from the left; each bar it is joined by another, and the row reads as the launch pipeline (launch → coin → agent → fees → post). The camera travels along the row.
- **Form**: a flight through one world, horizontal, never cutting.
- **Look**: white ground, Base Blue squares, black Base Sans captions under each square.
- **Sound**: a steady four-on-the-floor pulse, one kick per square.

## C. Before and after

- **Device**: life before and after. Left: a coin launched the usual way, silent after day two, the chart flat. Right: the same coin on Bootr, its agent posting through the night.
- **Form**: split screen to one; the right pane takes over the frame on the payoff.
- **Look**: left grey and still, right Base Blue and moving.
- **Sound**: near silence on the left, the bed opens when the right pane wins.
